Estrutura do Trabalho - Multimédia

Tema: Streaming e redes sociais

Descrição do projeto

O nosso trabalho consiste no desenvolvimento de um website estático relacionado com o tema “Multimédia”, mais especificamente sobre streaming e redes sociais. O site será desenvolvido utilizando HTML5 seguindo os requisitos definidos no enunciado.

Estrutura do Website

Página Inicial

  • Introdução ao tema
  • Imagens e destaques principais

Plataformas de Streaming

  • Informação sobre plataformas como Netflix, YouTube, Twitch e Spotify
  • Tabela comparativa de plataformas

Impacto das Redes Sociais

  • Influência das redes sociais na sociedade
  • Marketing digital

Estilo Visual

  • Cores escuras com destaques em vermelho e branco
  • Menus simples e organizados
  • Layout responsivo para computador e telemóvel

Tecnologias Utilizadas

  • HTML5
  • XML + XSD

Funcionalidades Previstas

  • Navegação entre páginas
  • Integração de imagens, áudio e vídeo

Apontamento Final

Pretendemos desenvolver um website simples, organizado e visualmente agradável, focado numa estrutura clara e de fácil navegação para o utilizador. O principal objetivo é garantir o cumprimento correto e rigoroso de todos os requisitos definidos no enunciado, assegurando a aplicação adequada das tecnologias HTML5
