# C1 : Título do Trabalho Prático

## Descrição

Este projeto foi desenvolvido no âmbito da unidade curricular de Tecnologias Internet, na área temática “Multimédia”, com foco em streaming e redes sociais.

O website foi desenvolvido utilizando HTML5, CSS3, JavaScript e XML/XSD, seguindo todos os requisitos definidos no enunciado do trabalho.

O objetivo principal consiste na criação de um website estático, moderno e responsivo, apresentando conteúdos relacionados com:

* plataformas de streaming;
* redes sociais;
* multimédia digital;
* impacto das tecnologias na sociedade.

O projeto inclui:

* 4 páginas HTML;
* integração de multimédia;
* formulários;
* tabelas;
* listas;
* integração dinâmica de XML com JavaScript;
* design responsivo;
* validação W3C.
