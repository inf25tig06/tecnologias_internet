# C3 : Produto

Este projeto consiste num website multimédia estático sobre plataformas de streaming e redes sociais.

O website foi desenvolvido utilizando:

* HTML5
* CSS3
* JavaScript
* XML + XSD

O principal objetivo é apresentar conteúdos relacionados com multimédia através de uma interface moderna, responsiva e interativa.

O website inclui:

* 4 páginas estáticas;
* conteúdos multimédia;
* formulários;
* tabelas e listas;
* integração XML;
* design responsivo;
* animações e transições CSS.

## 3.2 Utilização

O website não requer autenticação.

Os utilizadores podem:

* navegar entre todas as páginas;
* visualizar conteúdos multimédia;
* interagir com formulários;
* descarregar ficheiros XML e XSD.

Limitações:

* website apenas estático;
* sem base de dados;
* sem processamento server-side.

## 3.6 Detalhes de implementação

### Requisitos das páginas

|       Requisito      |                         Exemplo de utilização                         |
| :------------------: | :-------------------------------------------------------------------: |
| Pelo menos 4 páginas | `index.html`, `streaming.html`, `redes-sociais.html`, `contacto.html` |
|    1 documento XML   |                         `xml/plataformas.xml`                         |
|    1 documento XSD   |                         `xml/plataformas.xsd`                         |
|     Ficheiro CSS     |                            `css/style.css`                            |

### Validação XML

O documento XML foi validado utilizando:

* validadores XML;
* validação XSD.

O ficheiro XML referencia o schema através de:

```xml id="lx2ls6"
xsi:noNamespaceSchemaLocation="plataformas.xsd"
```
